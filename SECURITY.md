# Security policy

## Supported versions

| Version | Security fixes |
| --- | --- |
| Latest 1.x release | Supported |
| Older releases | Upgrade to the latest 1.x release |

## Report a vulnerability

Use GitHub private vulnerability reporting for the affected SDK first:

- [JavaScript](https://github.com/THUNDER-SOLUTION-CO-LTD/sdk-js/security/advisories/new)
- [PHP](https://github.com/THUNDER-SOLUTION-CO-LTD/sdk-php/security/advisories/new)
- [Python](https://github.com/THUNDER-SOLUTION-CO-LTD/sdk-python/security/advisories/new)
- [Go](https://github.com/THUNDER-SOLUTION-CO-LTD/sdk-go/security/advisories/new)

If you cannot use GitHub, use the [contact page](https://developer.thunder.in.th/contact). Never report vulnerabilities in public issues, pull requests or discussions.

Include the SDK and runtime versions, a minimal reproduction using synthetic data, the expected and actual behavior, and the possible security impact. Do not send API keys, webhook secrets, real slip images or customer data. Revoke any exposed credentials through the [developer portal](https://developer.thunder.in.th).

We acknowledge reports and keep the reporter updated as we investigate and prepare a fix. We agree on disclosure with the reporter. If you would like public credit, tell us how you want to be named.
